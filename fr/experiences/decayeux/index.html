Développeur Front-end

Decayeux

Mission de 2 mois chez Decayeux - Développement d'une application de déverrouillage de boîtes aux lettres

Mission Rennes, Bretagne, France · 🇫🇷 févr. 2021 - mars 2021
React React Native

Projet

Développement d’une application permettant le déverrouillage de boîtes aux lettres à distance pour un acteur majeur dans la fabrication de serrures de sécurité et de boîtes aux lettres. Le projet visait à offrir une solution sécurisée et pratique pour les utilisateurs.

Contexte

Le projet a été réalisé au sein d’une équipe de 2 développeurs. Mon rôle principal était de développer les fonctionnalités front-end de l’application en assurant une interface utilisateur intuitive et efficace.

Missions

Développement Front-end

  • Création d’interfaces utilisateur intuitives
  • Développement de vues pour l’application mobile
  • Implémentation des fonctionnalités de déverrouillage à distance
  • Optimisation de l’expérience utilisateur

Conception et intégration

  • Design d’interfaces responsives
  • Intégration des composants React et React Native
  • Mise en place des interactions avec le système de verrouillage

Organisation

  • Collaboration au sein d’une équipe de 2 développeurs
  • Documentation des fonctionnalités développées
