Développeur Full Stack

Neatro

Développeur principal pour une plateforme de rétrospectives Agile

Mission Montréal, Québec, Canada · 🇨🇦 avr. 2025 - En cours
React .NET Azure Agile

Projet

Développeur principal dans une équipe de 2 personnes pour Neatro, une startup développant une plateforme innovante de rétrospectives Agile. La plateforme est conçue pour accompagner les équipes modernes dans une démarche d’amélioration continue, favorisant la sécurité psychologique et augmentant la productivité d’équipe.

Contexte

Neatro est un outil de rétrospective en ligne spécifiquement conçu pour les équipes agiles distantes. Il offre un cadre structuré qui aide les équipes à examiner leurs processus, identifier les domaines d’amélioration et mettre en œuvre des actions concrètes pour progresser, établissant une culture d’apprentissage et d’adaptation continue.

Réalisations Principales

Développement de la Plateforme

  • Architecture et implémentation de l’application full-stack utilisant React pour le frontend et .NET pour le backend
  • Conception d’une interface utilisateur responsive pour une expérience de rétrospective intuitive accessible à tous les membres d’équipe
  • Implémentation de fonctionnalités de collaboration en temps réel permettant aux équipes de travailler ensemble de manière fluide

Intégration Cloud Azure

  • Développement d’une architecture cloud évolutive sur Azure pour gérer des charges variables
  • Mise en œuvre de systèmes d’authentification et d’autorisation sécurisés
  • Configuration de pipelines CI/CD pour le déploiement continu de nouvelles fonctionnalités

Implémentation de Fonctionnalités Agile

  • Création de fonctionnalités d’anonymat pour prévenir la pensée de groupe et créer un environnement psychologiquement sécuritaire
  • Développement de modèles de rétrospective personnalisables couvrant les méthodologies Agile populaires
  • Implémentation d’outils d’analyse pour mesurer les progrès de l’équipe dans le temps
  • Construction de systèmes de suivi des actions avec intégration aux outils de gestion de projet populaires
