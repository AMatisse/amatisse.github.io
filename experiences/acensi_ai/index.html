AI System Developer

Acensi

Montreal, Quebec, Canada🇨🇦

Intervention

Jan 2025 - Mar 2025 (2 months)

Python Machine Learning Natural Language Processing

Project

Development of an artificial intelligence system designed to streamline and optimize the management of technical tickets. The system employs machine learning techniques to analyze, categorize, and prioritize incoming technical issues, significantly improving response times and resource allocation.

Context

As part of Acensi’s initiative to modernize their ticket management system, I was brought in to develop an AI-powered solution that could handle the increasing volume of technical tickets more efficiently.

Key Achievements

Machine Learning Implementation

  • Designed and implemented a machine learning model for ticket analysis and prioritization
  • Developed algorithms to assess ticket urgency and complexity
  • Integrated natural language processing for improved ticket categorization

System Integration

  • Collaborated with the technical team to integrate the AI system with existing infrastructure
  • Created pattern recognition algorithms for automatic fault diagnosis
  • Implemented a feedback loop system for continuous model improvement

Performance Improvements

  • Reduced average ticket response time by 40%
  • Achieved 85% accuracy in ticket prioritization
  • Implemented automated diagnostic suggestions with 75% relevance rate
