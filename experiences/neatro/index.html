Neatro

Principal developer for an Agile retrospective platform

Mission Montreal, Quebec, Canada · 🇨🇦 Apr 2025 - Present
React .NET Azure

Project

Principal developer in a two-person team for Neatro, a startup developing an innovative Agile retrospective platform. The platform is designed to help modern teams continuously improve through collaborative retrospectives, fostering psychological safety and enhancing team productivity.

Context

Neatro is an online retrospective tool made specifically for remote agile teams. It provides a structured framework that helps teams review their processes, identify areas for improvement, and implement concrete actions to progress, establishing a culture of continuous learning and adaptation.

Key Achievements

Platform Development

  • Architected and implemented the full-stack application using React for the frontend and .NET for the backend
  • Designed responsive UI for an intuitive retrospective experience accessible to all team members
  • Implemented real-time collaboration features enabling teams to work together seamlessly

Azure Cloud Integration

  • Developed a scalable cloud architecture on Azure to handle varying loads
  • Implemented secure authentication and authorization systems
  • Set up CI/CD pipelines for continuous deployment of new features

Agile Feature Implementation

  • Created functionality for anonymity to prevent groupthink and create psychological safety
  • Developed customizable retrospective templates covering popular Agile methodologies
  • Implemented analytics tools to measure team progress over time
  • Built action tracking systems with integration to popular project management tools
